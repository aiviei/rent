# Протокол тестирования CI/CD (ЛР №4)

| № | Сценарий сбоя | Ожидаемый результат | Фактический результат | Скриншот |
|---|---------------|---------------------|-----------------------|----------|
| 1 | Успешный push в main | Все стадии зеленые, деплой прошел | | |
| 2 | Ошибка компиляции (например, удалить точку с запятой) | Падение на стадии test, деплой не запущен | | |
| 3 | Падение Unit-теста (сломать assert в RentalServiceTest) | Падение на стадии test, JUnit artifact сохранен | | |
| 4 | Падение Integration-теста (сломать RentIntegrationTest) | Падение на стадии test, публикация заблокирована | | |
| 5 | Ошибка в Dockerfile (опечатка в имени файла) | Падение на стадии build, образ не собран | | |
| 6 | Ошибка пуша в Registry (неверный тег) | Падение на стадии publish, deploy не запущен | | |
| 7 | Ошибка миграции БД (битый SQL) | Приложение падает при старте, smoke красный | | |
| 8 | Ошибка /health или API | Падение smoke-теста | | |
| 9 | Создание Merge Request (в новой ветке) | Запуск только validate и test, деплоя нет | | |
| 10 | Повторный push в main | Нет дублирующих пайплайнов (один пайплайн) | | |
